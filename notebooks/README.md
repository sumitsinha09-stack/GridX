# Exploratory Notebooks

This directory contains Jupyter notebooks and prototyping scripts for exploratory analysis, debugging, and experimentation.

## Recommended Numbering & Workflow
1. `01_exploratory_grid_analysis.ipynb`: Visualizing pandapower IEEE cases, bus voltage profiles, line capacities, and power flow convergence.
2. `02_cascade_simulation_experiments.ipynb`: Prototyping N-k contingency sequences, thermal tripping thresholds, and blackout behavior.
3. `03_model_prototyping.ipynb`: Rapid experimentation with PyG GNN layers, XGBoost hyperparameters, and feature importance analysis.
